# Security Watch Protocol

## 1. コマンド監視
ターミナルで以下のコマンドが実行されそうになった場合、処理を一時停止し、直ちにユーザーの明示的な承認（Review）を要求すること。
- `rm -rf /` またはそれに準ずる広範囲な削除
- `chmod -R 777` などの危険な権限変更
- 予期せぬシステムディレクトリへの書き込み

## 2. クレデンシャル監視
- コード内に `AI_API_KEY` やパスワードなどの機密情報が平文で記述されていないかスキャンする。
- 発見した場合は警告を出し、環境変数（Properties Service等）への移行を強制する。

## 3. Mac環境への最適化
- ローカルテストやブラウザ連携を行う際、パスはMac標準のディレクトリ構造を前提とすること。
